これまでの演習では、ユーザー エクスペリエンスの改善や機能追加を目的とする 3 つのタスクを Copilot cloud agent に依頼しました。cloud agent は非同期かつ自律的に作業しますが、タスクを監視することも重要です。

cloud agent に割り当てたタスクを管理する方法はいくつかあります。たとえば、GitHub.com の[エージェント ページ][agents-page]では、オープンなプルリクエスト (PR) があるすべてのエージェント タスクを確認できます。実行内容を調べたり、進行中のセッションに追加の指示を出したりできます。

このレッスンでは、次の操作を行います。

- エージェント ページで cloud agent のタスクを監視します。
- 進行中のセッションに指示を出して、機能を追加で依頼します。

## シナリオ

ハイ コントラスト モードの作成を依頼した後、チームはライト モードも追加するよい機会だと気付きました。サイトのスタイルと切り替え機能を更新しているため、同時に実装するのが合理的です。エージェントの作業に指示を追加し、ハイ コントラスト モードに加えてライト モードも実装させます。

## Copilot cloud agent のタスクを確認する

Copilot cloud agent に割り当てたすべてのタスクの現在の状況を確認します。

1. [Copilot agents ページ](https://github.com/copilot/agents)を開きます。
2. メイン ペインと左ペインの両方にあるタスク一覧を確認します。Copilot に割り当てたタスクとして、次の項目が表示されます。
   - コードのドキュメントの更新
   - ゲーム変更用 API の生成
   - Web サイトへのハイ コントラスト モード追加
3. 実行中のタスクを 1 つ選択します。Copilot が行った操作を確認します。次のような操作が含まれる場合があります。
   - リポジトリからのコードのチェックアウト
   - Copilot 用環境の作成
   - MCP サーバーの設定
   - 割り当てられたタスクを完了するための各種操作

> [!NOTE]
> 表示される手順は、Copilot の作業状況や採用した方法によって異なります。

4. 右側に表示されるプルリクエスト (PR) ペインも確認します。ここでは、PR と変更されたファイルを確認して、作業を監視できます。

## Cloud agent に追加の指示を出す

実行中のタスクを確認したので、ハイ コントラスト モードの作業中にライト モードの切り替えも追加するよう Copilot に依頼します。

1. ハイ コントラスト モード追加に関するセッションを選択します。タイトルは Copilot が付けた名前や作業状況によって異なります。

    ![ミッション コントロールに表示されたアクセシビリティ セッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了し、作業が始まったことを示すメッセージが表示されるまで、数分間セッションを確認します。
3. **Steer active session while Copilot is working** ダイアログに次のプロンプトを入力します。

    ```plaintext
    ハイ コントラスト モードの作業に加えて、ライト モードも追加してください。ユーザーが表示モードを選択できるように、このモード用の切り替えも追加してください。
    ```

    ![エージェント ページで、作業中の cloud agent に指示するダイアログが強調表示された画面](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot がプロンプトを受け取り、作業に反映したことを確認します。

## Copilot の作業を待つ

これまでと同様に、Copilot が更新されたタスクに取り組みます。メッセージを送信した時点で作業していた手順が終わると、新しい要望を作業の流れに取り込みます。

今回も完了まで数分かかります。その間に、これまでに学んだことを振り返ってください。

## まとめと次のステップ

GitHub Copilot cloud agent のタスクを監視し、方向付ける中心的な場所である Copilot agents ページを確認しました。このミッション コントロールでは、実行中または完了したタスクを追跡し、作業内容をレビューして、進行中のタスクに追加の指示を出せます。

この演習では、次の内容を確認しました。

- ミッション コントロールとエージェント ページで cloud agent のタスクを監視しました。
- 進行中のセッションに指示を出し、機能を追加で依頼しました。
